# Canvas zoom 1 — iPad Safari 验收

自动化浏览器测试不等于真实 iPad Safari、Apple Pencil 和系统照片选择器验收。
先保存当前画作，在新预览目录打开页面，确认顶部 `Canvas zoom 1`。

- [ ] 单指、Apple Pencil 都能画线。单指点一下能填色、放贴纸。
- [ ] 两指张开至约 200%，菜单、顶部按钮大小和位置不变。
- [ ] 在画板左／中／右不同位置张开、合拢，手指中心附近的图案留在手指附近（到画作边界时会限位）。
- [ ] 两指一起拖动，画作移动，页面和菜单不滚动、不放大。
- [ ] 放大后用右侧、底部的紫色滑条查看边缘；滑条不会画线。
- [ ] 使用 Fill 和贴纸工具时先放一根手指、再放第二根开始缩放，不应填色或盖章。
- [ ] 先用手指画一小段且不抬手，再落第二根手指：只取消正在画的这一笔，之前的画仍在。
- [ ] 缩放后先抬起一根手指，剩下一根继续移动，不应误画；全部抬起后单指可再次绘画。
- [ ] 放大后 Brush／Sparkle／Eraser 在手指／笔尖位置正确落点。
- [ ] 自画闭合区域、内置模板、从 Photos／Files 上传的 PNG 都可在放大、滚动后准确填色。
- [ ] Pencil 绘画时手掌靠近，不会突然进入缩放。双指缩放时不同时用 Pencil 作画。
- [ ] 横屏、竖屏、分屏切换后，画作比例不变；当前查看倍率保留，菜单仍可操作。
- [ ] Undo／Redo 撤销绘画而不是撤销视图；连续缩放不会耗尽 20 步绘画历史。
- [ ] `Fit` 恢复全图和 100%，对应方向无需滚动时滑条隐藏。
- [ ] 放大后 Save 导出的是整幅画，包含当前屏幕外的部分。
- [ ] 侧栏滚动到底后 Upload Picture 可打开系统照片／文件选择器。
- [ ] 页面切到后台再回来仍能继续画画；快速双击没有整页放大。
- [ ] 三根手指意外碰到后，全部抬起可以正常继续操作。

验证完成再提交 PR；不要仅凭“无合并冲突”跳过测试。
