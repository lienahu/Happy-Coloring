# Colorful F1 真机验收清单

先在新目录使用局域网 HTTP 预览。顶部（非紧凑手机模式）应显示 Colorful F1。
图库必须通过 HTTP/HTTPS 打开，不能使用 file:// 双击页面，因为目录通过 fetch 加载。
测试通过前不要合并 main。保留此前 stash，不删除仓库文件。

## iPhone 竖屏、横屏，iPad 竖屏、横屏

- 点 Tools → Fill，下面显示 15 种样式；选中后面板自动收起。
- 连续切换 Brush → Fill → Brush，点击不丢失；XS=2 px 保留。
- 画一个封闭圈，逐个测试 15 种样式；框外和黑线不应被改动。
- 在同一区域依次填圆点、星星、纯色；应替换整个区域，而非仅一个圆点。
- 试黑色和白色的花纹；它们也应能看出纹理。
- 做一次花纹填充 → Undo → Redo → 再换另一种花纹。
- 花纹区域中画一条分隔线，再填其中一侧，另一侧不变。
- 双指缩放、滚动后再填色，落点不偏移；选区缩放仍可用。
- 点 Pages → 图案库，依次选择容易、一般、困难；每类显示 10 张、分为两页（6+4）。
- 查看 30 张图案均能加载；五个原图快捷入口仍可用。
- 同一张图通过图库和 Upload 载入，检查均可填色。
- 关闭图库、切换难度或翻页，本来的画作不得被清除。
- 切换七种语言，按钮、难度、模板名称仍可读；短横屏能滚动到所有图案和选项。
- Save → 下载 PNG，确认整幅画的花纹和背景都保存；iPhone/iPad 原生分享请在可信 HTTPS 验证。
- 临时断网打开尚未载入的图案：应提示失败而不是清空画作；恢复网络可重试。

## 限制

Sparkle 是静态闪光纹理，不是动画。线稿仍需封闭，不自动补洞。
保存的 PNG 是合并像素：重新上传后不包含可编辑的花纹区域元数据。
框选缩放实际改变像素后，框内的花纹按普通像素处理；未改变的框外区域仍保留花纹信息。
本版没有自动保存画作；刷新前请先保存。
