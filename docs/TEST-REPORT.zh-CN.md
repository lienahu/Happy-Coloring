## 34 项单元测试覆盖

直接在 Node VM 中加载运行版 app.js，用桩隔离 DOM/Canvas API。验证的不是另外复制的一套算法。

* 画布只初始化一次；旋转和 20 次连续尺寸变化不重建位图；等比显示；零尺寸保护；高 DPR 内存上限；DPR 改变后坐标稳定。
* 指针原点和旋转后的坐标换算；小屏幕尺寸；VisualViewport 正常、缩放和缺失三种情况；合并重复布局调度。
* 非主指针/鼠标右键忽略；第二指针不能夺取当前笔画；错误 pointerup 不结束当前笔画；取消、失去捕获和旋转后的收尾。
* 五个真实工具按钮绑定；20 次撤销需要 21 个状态；恢复时不继承橡皮混合模式；旧异步恢复不能覆盖新状态。
* 黑色填入透明区域；闭合边界填色；越界点击保护。
* 仅在画板拦截 touchend；工具栏单指滚动不拦截；多指拦截；上传按钮不拦截双击；模板加载使用正常绘图模式。

完整名称与每项结果在 `evidence/unit.tap`；源码在 `tests/unit/`。

4. 画作的像素比例锁定在首次初始化；旋转后可能留白，而不是拉伸填满。刷新页面仍会丢失未保存画作，此次未增加持久化。
5. 保留当前 main 的简单程序模板；stash 中的漂亮图片、其他实验代码未合并。
6. 系统辅助缩放不由网页关闭；本包不声称已支持所有 OS/版本。
