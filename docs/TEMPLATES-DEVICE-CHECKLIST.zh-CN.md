# Colorful P1 — iPhone / iPad 验收

在新的预览目录用本地服务器打开，不要先部署 main。测试前保存已有作品。

- 每个模板按钮都显示对应的附件图：独角兽、公主、小猫、蝴蝶、长颈恐龙。
- 在五张图的主体以及一个独立小区域分别填色；颜色不要漏到图案外面。
- 用 Upload 选择 assets/coloring-pages 中同一张 PNG，比较与按钮载入的结果。
- 放大、两指拖动之后继续 Fill、Brush、Sparkle、Eraser，触点应准确。
- 连续切换模板后 Undo/Redo，应恢复正确的前后图片与填色。
- 选择一个模板后切换七种语言，模板按钮仍加载正确图片。
- iPhone/iPad 横竖屏切换、手机工具抽屉和滚动滑条仍可用。
- Save → Download PNG，检查完整图片确实保存，不只是屏幕可见部分。
- HTTPS 上验证原生分享；普通 HTTP 不能验证 iOS Share。
- 断网/图片加载失败时原画不应消失；快速选择不同模板最终显示最后一张。

不要用“按钮亮了”代替像素填色和文件落地检查。通过后再提交功能分支 PR。
