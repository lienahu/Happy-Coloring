# iPhone / iPad 真机检查 — Colorful E1

先保存已有画作。这个功能不增加自动保存；刷新网页可能丢失未保存的画。

## 笔宽与菜单

- 点击 Brush：下方出现 XS=2、S=8、M=16、L=28、XL=44。
- 选择 XS：面板收起；在画布上画线，比 S 明显细。Undo/Redo 正常。
- Sparkle、Outline、Eraser 选择笔宽后仍保留对应工具。
- 手机点击 Tools/Colors/Pages/Stickers：每个只显示相关内容，标题正确。
- Pages 中 Upload 仍能打开原生照片/文件选择器，选同一张图片两次也有效。
- 切换七种语言，笔宽和选区控件仍能看清、触达；没有横向溢出。
- 横竖屏、窄分屏、Safari 地址栏展开收起后工具栏与关闭按钮可达。

## 选区内容缩放

- 加载恐龙/蝴蝶等模板。选 Select/框选，拖出矩形，原画不能多出线条。
- 框选一个独立图案，四周留空；选区的 + / − 改变框内预览。
- 检查框外图案不动；放大超框会裁切，缩小会露出画纸背景。
- 取消后完全恢复；再操作并应用，Undo 一次恢复，Redo 一次重新应用。
- 选区框内两指张合只改变选区内容预览；不能触发全网页缩放。
- 编辑结束后，原全画布两指缩放/拖动和滚动滑条仍正常。
- 全画布先放大并滚动，再框选：框的位置、缩放目标都准确。
- 选区预览中转屏，不变形、不改框外像素；应用/取消按钮仍可用。
- 按取消、切换工具、手势取消或从后台回来，不出现卡住的手指状态。
- 应用后继续 Brush/Sparkle/Fill/贴纸正常；从三个入口（自画/模板/上传）测试 Fill。
- Save 下载整张已应用的图片，不包含选框虚线；iPhone HTTPS 分享照常验收。

## 限制

矩形缩放不是抠图，不会补齐或重画被框切断的边缘，也不是放大镜窗口。
若只需要看细节，不改变保存的画作，请用原来的全画布双指缩放。
